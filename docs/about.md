# About Mango Labs

Mango Labs is an independent Android development studio focused on building apps that are simple, useful, and well-crafted.

## Our Philosophy

We believe great software should be:

- **Simple** — easy to understand and use from the first launch
- **Useful** — solves a real problem without unnecessary bloat
- **Well-crafted** — built with modern Android best practices and attention to detail
